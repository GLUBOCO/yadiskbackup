# Яндекс.Диск — Аварийный Загрузчик (v2.3.17)

**YaDiskBackup** — бесплатная утилита на Python с графическим интерфейсом для сохранения файлов из общедоступных папок Яндекс.Диска на компьютер.

Программа пытается скачать оригиналы файлов, а если оригинал недоступен — получить превью, когда оно доступно. Это может помочь сохранить часть данных, если загрузка оригиналов не работает. Восстановление всех файлов не гарантируется.

Разработано командой маркетингового агентства [Gluboco](https://glubo.ru/).

## 🛠 Что умеет программа

- **Скачивает оригиналы** файлов, если они доступны на серверах Яндекса.
- **Пытается сохранить превью**, если оригинал скачать не удалось и превью доступно.
- **Позволяет повторить попытку загрузки оригиналов** для файлов, у которых сохранились превью.
- **Пропускает уже скачанные файлы**, чтобы не загружать их повторно без необходимости.
- **Ведёт журнал загрузки** с информацией об ошибках и результатах обработки файлов.
- **Формирует отчёты** о результатах загрузки, включая файлы, которые не удалось скачать.
- **Поддерживает остановку и продолжение работы**, сохраняя уже скачанные файлы.

Результат зависит от доступности файлов, ответов серверов Яндекса и ограничений доступа. Наличие превью не гарантирует возможность получить оригинал.

## 💻 Запуск из исходного кода

Для запуска программы из исходного кода понадобится Python 3.12 и файлы репозитория.

1. Скачайте репозиторий или клонируйте его.
2. Откройте терминал в папке проекта.
3. Установите зависимости:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Запустите программу:

   ```bash
   python YaDiskBackup_v2_3_17.py
   ```
