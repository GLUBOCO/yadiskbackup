# Яндекс.Диск — Аварийный Загрузчик (v2.3.14)

Бесплатная утилита на Python с графическим интерфейсом для аварийного выкачивания файлов с Яндекс.Диска в условиях ЧС (когда оригиналы данных повреждены или стерты на серверах).

Разработано командой маркетингового агентства [Gluboco](https://glubo.ru).

---

## 🛠 Что умеет софт:
* **Выкачивает оригиналы файлов**, если они еще уцелели и доступны на серверах Яндекса.
* **Автоматически спасает превью из веб-кэша** в максимальном качестве (до 1080p), если оригинальные файлы не доступны или заблокированы.
* **Работает строго в один поток** с контролируемыми таймаутами, чтобы Яндекс не забанил сессию по IP во время массового скачивания.
* **Автоматически пропускает дубли** (уже скачанные файлы) и фиксирует все ошибки в локальный лог-файл.

---

## 💻 Запуск из исходного кода:
Если вы хотите запустить утилиту как скрипт, вам понадобятся файлы репозитория.

1. Установите библиотеку для работы с сетью:
   ```bash
   pip install requests
   ```
2. Запустите скрипт через терминал:
   ```bash
   python YaDiskBackup_v2_3_14.py
   ```
